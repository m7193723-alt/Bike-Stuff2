BIKE STUFF — демонстрационный многостраничный сайт

Файлы:
index.html       Главная
catalog.html     Каталог с поиском, фильтрами, брендами и демонстрационными ценами
cart.html        Корзина и форма заявки в Telegram
reviews.html     Раздел отзывов (макеты, не реальные отзывы)
deliveries.html  Галерея доставок (иллюстративные изображения)
shipping.html   Доставка и заказ
about.html       О компании
contacts.html    Контакты
style.css        Общие стили
script.js        Каталог, корзина и оформление заявки

Как загрузить:
1. Распакуйте архив.
2. Загрузите ВСЕ файлы в корень одного GitHub-репозитория.
3. В GitHub откройте Settings -> Pages.
4. В разделе Build and deployment выберите Deploy from a branch.
5. Выберите main и /(root), затем Save.

Важно:
- Это демоверсия. Цены и товарные позиции примерные, перед публикацией их нужно проверить и заменить.
- Фотографии загружаются из Unsplash по интернету и служат иллюстрациями; они не подтверждают конкретные модели или наличие товара.
- Корзина хранится в браузере покупателя (localStorage).
- Отправка заказа открывает Telegram с подготовленным текстом. Пользователь должен сам нажать Send в Telegram.
- Онлайн-оплаты, базы данных и админ-панели нет.
- Для production-сайта проверьте права на использование фото, товарные данные, юридические документы и условия продажи.
